How to use Redact PDF

Frequently asked questions

Is Redact PDF free?

Yes. The free plan covers this tool with no sign-up required.

Is my file uploaded anywhere?

No. This tool runs entirely in your browser, so your PDF never leaves your device.

Which file types are supported?

Supported: .pdf. Files up to 50 MB are supported on the free plan.

Is the redaction permanent?

Yes. Pages with matches are re-rendered as images with the matched text blacked out, so the hidden text can’t be copied or recovered. Pages without matches are left untouched.
